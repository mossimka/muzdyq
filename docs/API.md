# API reference

Base URL locally: `http://127.0.0.1:8000` (dev) or `http://localhost:8080`
(Compose, same-origin `/api`). Interactive docs: `/docs` (Swagger UI) and
`/redoc`. Machine schema: `/openapi.json`.

All photo metadata and images are licensed **CC BY 4.0**. Code is MIT.

## Conventions

- JSON responses use UTF-8 and snake_case field names.
- Timestamps are ISO-8601 UTC with `Z`, e.g. `2026-07-01T09:00:00Z`.
- Localised text is an object: `{"en": "...", "ru": "...", "kk": "..."}`.
- Public reads never require authentication. There are **no accounts**.
- Uploads are anonymous; the server stores only salted hashes of the IP and an
  optional device token for rate limiting and duplicate-abuse correlation.
- Errors return FastAPI's `{"detail": ...}`. Validation errors may include a
  structured detail such as `{"code": "duplicate_photo", "message": "..."}`.

## Points

### `GET /api/points`

Returns every monitoring point with viewpoints, published-photo count and the
latest thumbnail.

```json
[
  {
    "id": 1,
    "slug": "tuyuksu-glacier",
    "type": "glacier",
    "name_i18n": {"en": "Tuyuksu Glacier", "ru": "Ледник Туюксу", "kk": "Тұйықсу мұздығы"},
    "description_i18n": {"en": "...", "ru": "...", "kk": "..."},
    "safety_note_i18n": {"en": "...", "ru": "...", "kk": "..."},
    "lat": 43.0417,
    "lon": 77.0792,
    "elevation_m": 3450,
    "coords_verified": false,
    "viewpoints": [
      {
        "id": "tuyuksu-glacier-v1",
        "heading_deg": 178,
        "note_i18n": {"en": "..."},
        "reference_photo_url": "/api/viewpoints/tuyuksu-glacier-v1/reference"
      }
    ],
    "photo_count": 5,
    "latest_photo_at": "2025-08-11T08:00:00Z",
    "latest_thumb_url": "/api/photos/<uuid>/thumb",
    "demo": true
  }
]
```

`coords_verified` is `false` for every seeded point. Treat coordinates as
approximate. `demo` marks points whose current photos are synthetic.

### `GET /api/points/{slug}`

Same object for one point; `404` if the slug is unknown.

## Photos

### `GET /api/points/{slug}/photos`

Published photos, newest first.

| Query | Type | Default | Meaning |
| --- | --- | --- | --- |
| `year` | int | — | Shortcut for a calendar year |
| `from` | date/year | — | Inclusive lower bound (`YYYY-MM-DD` or `YYYY`) |
| `to` | date/year | — | Inclusive upper bound |
| `limit` | int 1–100 | 24 | Page size |
| `cursor` | string | — | Opaque cursor from `next_cursor` |

```json
{
  "items": [
    {
      "id": "0e0b0c1e-...",
      "point_id": 1,
      "point_slug": "tuyuksu-glacier",
      "viewpoint_id": "tuyuksu-glacier-v1",
      "taken_at": "2025-08-11T08:00:00Z",
      "uploaded_at": "2025-08-12T08:00:00Z",
      "width": 1600,
      "height": 1200,
      "bytes": 240123,
      "license": "CC-BY-4.0",
      "tags": {"weather": "clear", "snow_cover": "partial", "automation": {"exif_stripped": true}},
      "is_demo": false,
      "url": "/api/photos/0e0b0c1e-.../file",
      "thumb_url": "/api/photos/0e0b0c1e-.../thumb",
      "download_url": "/api/photos/0e0b0c1e-.../file?download=true"
    }
  ],
  "next_cursor": "MjAyNS0wOC0xMVQwODowMDowMFp8..."
}
```

`taken_at` is deliberately rounded down to the hour.

### `POST /api/points/{slug}/photos`

`multipart/form-data`, anonymous.

| Field | Required | Notes |
| --- | --- | --- |
| `file` | yes | JPEG/PNG/WebP, ≤ 15 MB (configurable) |
| `viewpoint_id` | yes | Must belong to `slug` |
| `taken_at` | yes | ISO-8601 with timezone; rounded to the hour |
| `client_uuid` | yes | UUID generated by the client; idempotency key |
| `tags` | no | JSON object; only `weather`, `visibility`, `snow_cover` are kept |

Allowed tag values:

- `weather`: `clear`, `partly_cloudy`, `overcast`, `fog`, `rain`, `snow`
- `visibility`: `good`, `medium`, `poor`
- `snow_cover`: `none`, `partial`, `full`

Optional header `X-Device-Token`: any opaque random string. It is hashed and
used only for rate limiting.

Responses:

| Status | Meaning |
| --- | --- |
| `201` | Created and published (`X-Photo-Status: published`) |
| `200` | Idempotent replay (`X-Idempotent-Replay: true`) |
| `409` | Near-duplicate image or UUID reused for another point |
| `413` | File too large |
| `415` | Unsupported MIME type |
| `422` | Invalid UUID, viewpoint, tags, timestamp or image |
| `429` | Rate limited; honour `Retry-After` |

Server-side processing: MIME + magic-byte validation, EXIF removal, resize to a
2048 px long edge, JPEG re-encode, face blur, thumbnail, perceptual hash and
duplicate check against recent photos of the same point.

```json
{
  "photo": { "...": "PhotoOut" },
  "duplicate": false
}
```

### `GET /api/photos/{id}/file`

Published image, EXIF-free. Add `?download=true` for an attachment. Sends
`X-Data-License: CC BY 4.0`. `404` when the photo is missing or not published.

### `GET /api/photos/{id}/thumb`

480 px long-edge JPEG thumbnail.

### `GET /api/viewpoints/{id}/reference`

Reference image used for the ghost overlay. `404` if none is configured.

## Exports

All export endpoints are public, read-only and stream the response.

| Endpoint | Format | Contents |
| --- | --- | --- |
| `GET /api/export/photos.csv` | CSV | Metadata table, one row per published photo |
| `GET /api/export/photos.geojson` | GeoJSON | `FeatureCollection`; geometry is the point location |
| `GET /api/export/photos.json` | JSON | Bundle with licence, attribution and disclaimer |
| `GET /api/export/photos.zip` | ZIP | Images + `photos.csv` + `LICENSE.txt` + `README.txt` |

Shared query parameters: `point=<slug>`, `from=<date|year>`, `to=<date|year>`.

CSV columns: `photo_id`, `point_slug`, `point_name_en`, `point_type`,
`viewpoint_id`, `taken_at`, `uploaded_at`, `lat`, `lon`, `elevation_m`, `width`,
`height`, `bytes`, `license`, `weather`, `visibility`, `snow_cover`, `is_demo`,
`photo_url`, `thumb_url`.

Every response includes:

```
X-Data-License: CC-BY-4.0
Link: <https://creativecommons.org/licenses/by/4.0/>; rel="license"
```

Attribution: *Muzdyq Citizen Science Photo Archive, CC BY 4.0*.

## Health

### `GET /api/health`

```json
{
  "status": "ok",
  "version": "0.1.0",
  "time": "2026-11-18T03:05:41Z",
  "database": "ok",
  "storage": "ok",
  "counts": {"points": 7, "viewpoints": 8, "photos": 35, "published": 35},
  "face_detection": {"available": true, "engine": "yunet"}
}
```

`status` is `degraded` when the database or storage check fails. The endpoint is
safe for container healthchecks and never exposes secrets.

## Admin / moderation

Every `/api/admin/*` request requires `X-Admin-Token: <ADMIN_TOKEN>`. Wrong or
missing tokens return `401`. These endpoints are not used by the PWA.

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/admin/photos?status=pending&limit=100` | Queue, newest first |
| `GET` | `/api/admin/stats` | Counts per status |
| `POST` | `/api/admin/photos/{id}/publish` | Publish a photo |
| `POST` | `/api/admin/photos/{id}/hide` | Hide; optional JSON `{"reason": "..."}` |
| `DELETE` | `/api/admin/photos/{id}` | Delete row and files (`204`) |

Statuses: `pending`, `published`, `hidden`, `rejected`.

```bash
curl -s -H "X-Admin-Token: $ADMIN_TOKEN" \
  "http://localhost:8000/api/admin/photos?status=pending"
```

The default token is a development placeholder. Change `ADMIN_TOKEN` before any
public deployment; the API logs a warning while the default is in use.

## Rate limits

Uploads are limited per `(salted IP hash, salted device hash)`:

- `UPLOAD_LIMIT_PER_MINUTE` (default 6)
- `UPLOAD_LIMIT_PER_HOUR` (default 40)

Reads and exports are not rate limited in this reference implementation. Put a
CDN or reverse-proxy limit in front of a high-traffic deployment.
