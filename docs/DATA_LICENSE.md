# Data licence and attribution

Muzdyq separates the licence of the **software** from the licence of the
**photos and metadata**.

| Material | Licence | Full text |
| --- | --- | --- |
| Source code, configs, docs, seed scripts | **MIT** | [LICENSE](../LICENSE) |
| Published photographs (including thumbnails) | **CC BY 4.0** | <https://creativecommons.org/licenses/by/4.0/> |
| Photo metadata and exports (CSV, GeoJSON, JSON, ZIP contents) | **CC BY 4.0** | same |
| Seeded demo photographs and reference frames | **CC BY 4.0** (synthetic, see below) | same |
| Map tiles from OpenStreetMap | **ODbL 1.0** | © OpenStreetMap contributors |
| Map tiles from OpenTopoMap | **CC BY-SA 3.0** | © OpenTopoMap contributors |

CC BY 4.0 is a human- and machine-readable licence that allows sharing and
adaptation for any purpose, including commercially, provided attribution is
given, a link to the licence is included, and changes are indicated.

---

## Required attribution

For photos and metadata, use this form (or a link to it):

> **Muzdyq Citizen Science Photo Archive** — “Tuyuksu Glacier, 2025-08-11” —
> CC BY 4.0. Source: https://github.com/muzdyq/muzdyq

Because contributors are anonymous by design, credit is given to the project and
its contributors rather than to a named photographer:

> “Photo: Muzdyq contributors, CC BY 4.0.”

When reusing a single photo, include:

1. the title or point name and year;
2. the attribution string above;
3. a link to the CC BY 4.0 deed;
4. an indication of changes (crop, colour adjustment, overlay, etc.).

Each image response already carries `X-Data-License: CC BY 4.0`. Exports carry an
`X-Data-License` header, a `Link: <…>; rel="license"` header, and a licence file
inside the ZIP.

Suggested citation for a dataset download:

```
Muzdyq contributors (2026). Muzdyq Citizen Science Photo Archive: Ile Alatau
glaciers and water bodies [Data set]. CC BY 4.0.
https://github.com/muzdyq/muzdyq
```

## What CC BY 4.0 does not mean

- It does **not** make the photos scientifically valid measurements. They are
  observations; see the disclaimer below.
- It does **not** grant rights to identify or contact people in the photos.
  Privacy and personality rights still apply.
- It does **not** grant rights to imply endorsement by Muzdyq, its contributors,
  glaciologists or any protected-area authority.
- It does **not** cover the Muzdyq name, logo or visual identity as trademarks.

## Disclaimer carried with exports

> Citizen photos are observations, not measurements. Conclusions about glacier
> state require verification by scientists.

Do not strip this disclaimer or the `is_demo` flag when redistributing data. The
`is_demo` flag is `true` for synthetic seed content and must remain visible so
that demo material is never mistaken for a real observation.

## Demo and reference imagery

Every seeded photo is generated by `backend/app/seed.py` at startup:

- it is a synthetic mountain/lake scene drawn with Pillow and NumPy;
- it is stamped **“DEMO PHOTO — NOT A REAL OBSERVATION”**;
- it is marked `is_demo: true` in the database and every export;
- the reference frames are stamped **“REFERENCE VIEW — DEMO FRAME”**;
- no real glacier, lake, person or location is depicted.

These images exist to make the prototype demonstrable and reproducible. Replace
them with real, contributor-owned photos before launch and set
`SEED_DEMO=false`.

The CC0 test face used **only by the automated test suite**
(`backend/tests/assets/face.jpg`, Léa Dubedout via Unsplash/Wikimedia Commons) is
not part of the application data and is not served by the API.

## Takedown and corrections

If you are depicted in a photo, or you believe a photo infringes your rights,
contact the maintainers with the photo URL or ID. We will hide the photo while
the request is reviewed and delete it if the concern is substantiated. No account
is required to make a request.

If a coordinate, viewpoint or description is wrong, open an issue with a source
and, where possible, field-verified evidence. Corrections are published under the
same licences.
