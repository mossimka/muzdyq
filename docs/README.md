# Muzdyq documentation

Muzdyq is an account-free, open citizen-science photo archive for the glaciers
and water bodies of the Ile Alatau. Start with a README in your language, then
use the reference documentation below.

## Help translate

Translations live next to this file as `README.<locale>.md`. To add a language:

1. Copy `README.ru.md` (or the English README) and translate the prose.
2. Keep commands, paths, URLs and code identifiers unchanged.
3. Add the language to the table above and to the language switcher in
   `../README.md`.
4. Do not translate the scientific disclaimer into a weaker claim: citizen
   photos are observations, not measurements.
5. Open a pull request. Native-speaker review is very welcome.
