# Muzdyq · Мұздық

[English](../README.md) · **Русский** · [Қазақша](README.kk.md) · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (BR)](README.pt-BR.md)

**Открытый гражданско-научный фотоархив ледников и водоёмов Заилийского Алатау
(Иле Алатау), Казахстан — без аккаунтов, отслеживания геолокации и аналитики.**

Muzdyq (по-казахски — «лёд, ледник») позволяет любому человеку на маркированной
тропе сделать повторяющийся снимок с фиксированной точки обзора. Со временем
такие фотографии становятся открытым визуальным рядом наблюдений за сокращением
ледников и изменением горных озёр.

- **Веб-приложение:** React 19 + TypeScript + Vite PWA, Ant Design, MapLibre GL,
  казахский / русский / английский.
- **API:** FastAPI + SQLAlchemy 2 + PostgreSQL/PostGIS (SQLite для разработки).
- **Открытые данные:** экспорт CSV, GeoJSON, JSON и ZIP по лицензии **CC BY 4.0**.
- **Код:** **MIT**.

> [!IMPORTANT]
> Координаты 7 точек в демонстрационном каталоге **приблизительные и
> непроверенные** (`coords_verified: false`). Их необходимо проверить на месте и
> с гляциологами до любого публичного запуска. См.
> [`backend/seed/points.json`](../backend/seed/points.json) и
> [`ETHICS.md`](ETHICS.md).
>
> **Фотографии граждан — это наблюдения, а не измерения.** Они не заменяют
> гляциологический баланс массы, геодезические съёмки или работу научных станций.

## Быстрый старт

### Вариант A — Docker Compose (рекомендуется)

Требуется Docker Engine 24+ с плагином Compose. Команды выполняются из корня
репозитория.

```bash
cp .env.example .env
docker compose up --build
```

Откройте **<http://localhost:8080>**. Первый запуск занимает примерно 15–30 секунд:
backend применяет миграции, загружает 7 точек и 8 точек съёмки, а также
генерирует 35 явно помеченных синтетических демо-фотографий.

| Адрес | Назначение |
| --- | --- |
| <http://localhost:8080> | PWA: карта, галерея, съёмка, экспорт |
| <http://localhost:8080/docs> | Интерактивная документация OpenAPI |
| <http://localhost:8000/api/health> | Состояние API напрямую |
| <http://localhost:8080/api/export/photos.geojson> | Экспорт открытых данных |

Остановка: `docker compose down`. Флаг `-v` удаляет также тома базы данных и
медиафайлов.

### Вариант B — локальная разработка

Backend (Python 3.12+):

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
uvicorn app.main:app --reload
```

API будет доступен на <http://127.0.0.1:8000>. Используются SQLite
(`backend/data/muzdyq.db`) и локальный каталог медиафайлов; демо-данные
создаются при старте.

Frontend (Node 22+):

```bash
cd frontend
npm ci
npm run dev
```

Откройте <http://127.0.0.1:5173>. Vite проксирует `/api`, `/media`, `/docs` и
`/openapi.json` на backend, поэтому CORS и ключи API не нужны.

## Возможности

### Карта и панель точки
- Растровая карта MapLibre (OpenStreetMap; OpenTopoMap в подробном режиме),
  маркеры ледников и водоёмов.
- Боковая панель на компьютере и нижняя панель на телефоне: описание, памятка
  по безопасности, координаты, высота и предупреждение о непроверенных данных.
- Выбор точки съёмки, эталонное фото и QR-ссылка для табличек на тропе.
- Фильтр по году, сравнение «до / после», клиентский таймлапс и галерея.
- Скачивание CSV, GeoJSON, JSON и ZIP для выбранной точки и всего архива.

### Съёмка (`/p/:slug/:viewpointId`)
- Задняя камера, если доступна, либо выбор файла.
- Полупрозрачное **эталонное наложение** с регулируемой прозрачностью.
- Необязательные теги: погода, видимость, снежный покров.
- Сжатие на устройстве (~1600 px, JPEG 0.75), удаление EXIF/GPS, пикселизация
  лиц в браузере и создание миниатюры.
- Очередь загрузки в IndexedDB, идемпотентный UUID, экспоненциальная задержка,
  ручная повторная отправка и Background Sync, где он поддерживается.
- Зелёный режим включён по умолчанию: лёгкие тайлы, без автовоспроизведения,
  загрузка области карты для офлайна и отсутствие аналитики.

### Backend
- Анонимная загрузка, без аккаунтов и личности автора.
- Проверка MIME и размера на сервере, удаление EXIF, размытие лиц (OpenCV YuNet,
  резервный Haar), миниатюры, перцептивный хеш для поиска дублей, округление
  `taken_at` до часа и ограничение частоты по хешам IP/устройства.
- Модерация через `X-Admin-Token`; в интерфейсе эти эндпоинты не используются.
- Экспорт содержит метаданные, координаты, лицензию и научную оговорку.

### Языки и доступность
- Казахский, русский и английский интерфейсы; переключатель виден всегда.
- Тёмная тема, навигация с клавиатуры, skip-link и контраст, рассчитанный на
  WCAG; проверка вёрстки при ширине 360 px.

## API кратко

Публичные эндпоинты не требуют аутентификации.

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/points` | Все точки с точками съёмки и числом фото |
| `GET` | `/api/points/{slug}` | Одна точка |
| `GET` | `/api/points/{slug}/photos` | Опубликованные фото; `year`, `from`, `to`, `cursor` |
| `POST` | `/api/points/{slug}/photos` | Анонимная загрузка; `client_uuid` делает повторы безопасными |
| `GET` | `/api/export/photos.csv` | Метаданные в CSV |
| `GET` | `/api/export/photos.geojson` | GeoJSON |
| `GET` | `/api/export/photos.json` | JSON-набор с лицензией |
| `GET` | `/api/export/photos.zip` | Изображения + метаданные + лицензия |
| `GET` | `/api/health` | Состояние сервиса, БД и хранилища |
| `GET` | `/docs` | Swagger UI |

Полное описание: [`API.md`](API.md) и `/docs` на запущенном сервере.

Пример загрузки:

```bash
curl -X POST http://localhost:8080/api/points/tuyuksu-glacier/photos \
  -F "file=@photo.jpg" \
  -F "viewpoint_id=tuyuksu-glacier-v1" \
  -F "taken_at=2026-07-01T09:00:00Z" \
  -F "client_uuid=$(uuidgen)" \
  -F 'tags={"weather":"clear","snow_cover":"partial"}'
```

## Тесты

```bash
# Backend
cd backend
./venv/bin/ruff check app tests
./venv/bin/pytest -q                 # 28 тестов

# Frontend
cd frontend
npm run lint
npx tsc -b
npm test                             # 14 тестов Vitest
npm run build
npm run e2e                          # Playwright, 3 профиля
```

Тесты backend покрывают удаление EXIF, размытие лиц, идемпотентность загрузки,
экспорт и ограничение частоты. Тест очереди проверяет повторные попытки и
повторное использование UUID. Playwright использует замоканный API и не требует
запущенного backend.

## Конфигурация

Скопируйте [`.env.example`](../.env.example) в `.env`. Основные параметры:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `DATABASE_URL` | SQLite в `backend/data/` | В Compose — `postgresql+psycopg://…` |
| `MEDIA_ROOT` | `./data/media` | Оригиналы и миниатюры |
| `ADMIN_TOKEN` | значение для разработки | **Смените перед публикацией** |
| `IP_HASH_SALT` | значение для разработки | **Смените перед публикацией** |
| `SEED_DEMO` | `true` | Синтетические демо-фотографии |
| `UPLOAD_LIMIT_PER_HOUR` | `40` | Лимит на хеш IP/устройства |
| `PUBLIC_BASE_URL` | пусто | Абсолютные ссылки в экспорте |

## Приватность и этика

- Нет аккаунтов, профилей, рейтингов, лидербордов, серий и значков.
- GPS и EXIF не загружаются и не публикуются: их удаляет клиент и повторно сервер.
- Лица размываются по возможности на устройстве и обязательно на сервере.
- Нет сторонней аналитики, трекеров и рекламных cookie.
- Фотографии публикуются по **CC BY 4.0**; автор подтверждает право на публикацию.
- На каждом пути съёмки показываются правила безопасности. Не выходите за
  маркированную тропу, не подходите к леднику, морене, воде или крутому снегу
  ради фотографии.

Подробнее: [`ETHICS.md`](ETHICS.md) и страница «Этика и приватность» в приложении.
