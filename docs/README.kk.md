# Muzdyq · Мұздық

[English](../README.md) · [Русский](README.ru.md) · **Қазақша** · [简体中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Português (BR)](README.pt-BR.md)

**Іле Алатауы мұздықтары мен су айдындарының ашық, азаматтық ғылымға негізделген
фотоархиві — тіркелгісіз, геолокацияны бақылаусыз және аналитикасыз.**

Muzdyq (қазақша — «мұздық») белгіленген соқпақтағы кез келген адамға бекітілген
көрініс нүктесінен қайталанатын сурет түсіруге мүмкіндік береді. Уақыт өте бұл
фотолар мұздықтардың азаюы мен тау көлдерінің өзгеруін көрсететін ашық
визуалды бақылау қатарына айналады.

- **Веб-қосымша:** React 19 + TypeScript + Vite PWA, Ant Design, MapLibre GL,
  қазақша / орысша / ағылшынша.
- **API:** FastAPI + SQLAlchemy 2 + PostgreSQL/PostGIS (әзірлеу үшін SQLite).
- **Ашық деректер:** CSV, GeoJSON, JSON және ZIP экспорты, **CC BY 4.0**.
- **Код:** **MIT**.

> [!IMPORTANT]
> Демо-каталогтағы 7 нүктенің координаттары **шамамен алынған және
> тексерілмеген** (`coords_verified: false`). Оларды жария іске қоспас бұрын
> гляциологтармен бірге жергілікті жерде тексеру қажет. Қараңыз:
> [`backend/seed/points.json`](../backend/seed/points.json) және
> [`ETHICS.md`](ETHICS.md).
>
> **Азаматтардың фотолары — бақылау, өлшем емес.** Олар мұздық массасының
> балансын, геодезиялық өлшеулерді немесе ғылыми станциялардың жұмысын
> алмастырмайды.

## Жылдам бастау

### A нұсқа — Docker Compose (ұсынылады)

Docker Engine 24+ және Compose плагині қажет. Командаларды репозиторий
түбірінен орындаңыз.

```bash
cp .env.example .env
docker compose up --build
```

**<http://localhost:8080>** мекенжайын ашыңыз. Алғашқы іске қосу шамамен
15–30 секунд алады: backend миграцияларды қолданып, 7 нүкте мен 8 көрініс
нүктесін жүктейді және анық белгіленген 35 синтетикалық демо-фото жасайды.

| Мекенжай | Мақсаты |
| --- | --- |
| <http://localhost:8080> | PWA: карта, галерея, түсіру, экспорт |
| <http://localhost:8080/docs> | Интерактивті OpenAPI құжаттамасы |
| <http://localhost:8000/api/health> | API күйі тікелей |
| <http://localhost:8080/api/export/photos.geojson> | Ашық деректер экспорты |

Тоқтату: `docker compose down`. `-v` флагы дерекқор мен медиа томдарын да
жояды.

### B нұсқа — жергілікті әзірлеу

Backend (Python 3.12+):

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
uvicorn app.main:app --reload
```

API <http://127.0.0.1:8000> мекенжайында жұмыс істейді. SQLite
(`backend/data/muzdyq.db`) және жергілікті медиа каталогы қолданылады; демо
деректер іске қосылу кезінде жасалады.

Frontend (Node 22+):

```bash
cd frontend
npm ci
npm run dev
```

<http://127.0.0.1:5173> мекенжайын ашыңыз. Vite `/api`, `/media`, `/docs` және
`/openapi.json` сұрауларын backend-ке проксилейді, сондықтан CORS пен API
кілттері қажет емес.

## Мүмкіндіктер

### Карта және нүкте панелі
- MapLibre растрық картасы (OpenStreetMap; толық режимде OpenTopoMap), мұздық
  және су айдыны маркерлері.
- Компьютерде бүйір панель, телефонда төменгі панель: сипаттама, қауіпсіздік
  ескертуі, координаттар, биіктік және тексерілмеген деректер туралы ескерту.
- Көрініс нүктесін таңдау, эталондық сурет және соқпақтағы тақтайшалар үшін
  QR сілтеме.
- Жыл сүзгісі, «дейін / кейін» салыстыруы, клиенттік таймлапс және галерея.
- Таңдалған нүкте және бүкіл архив үшін CSV, GeoJSON, JSON, ZIP жүктеу.

### Түсіру (`/p/:slug/:viewpointId`)
- Қолжетімді болса, артқы камера; әйтпесе файл таңдау.
- Реттелетін мөлдірлікпен **эталондық қабаттама**.
- Міндетті емес тегтер: ауа райы, көріну, қар жамылғысы.
- Құрылғыда сығу (~1600 px, JPEG 0.75), EXIF/GPS жою, браузерде беттерді
  бұлдырату және кіші сурет жасау.
- IndexedDB жүктеу кезегі, идемпотентті UUID, экспоненциалды кідіріс, қолмен
  қайта жіберу және қолдайтын браузерлерде Background Sync.
- Жасыл режим әдепкі бойынша қосулы: жеңіл тайлдар, автоплей жоқ, офлайн үшін
  карта аймағын жүктеу және аналитика жоқ.

### Backend
- Анонимді жүктеу, тіркелгілер мен автор жеке басы жоқ.
- Серверде MIME мен өлшемді тексеру, EXIF жою, беттерді бұлдырату (OpenCV
  YuNet, қосалқы Haar), кіші суреттер, қайталануларды табуға арналған
  перцептивті хеш, `taken_at` уақытын сағатқа дейін дөңгелектеу және IP/құрылғы
  хештері бойынша жүктеу жиілігін шектеу.
- `X-Admin-Token` арқылы модерация; интерфейсте бұл эндпоинттер қолданылмайды.
- Экспорт метадеректерді, координаттарды, лицензияны және ғылыми ескертуді
  қамтиды.

### Тілдер мен қолжетімділік
- Қазақша, орысша және ағылшынша интерфейстер; тіл ауыстырғыш әрдайым көрінеді.
- Қараңғы тақырып, пернетақтамен басқару, skip-link және WCAG-қа бағытталған
  контраст; ені 360 px болатын орналасу тексерілген.

## API қысқаша

Жария эндпоинттер аутентификацияны талап етпейді.

| Әдіс | Жол | Мақсаты |
| --- | --- | --- |
| `GET` | `/api/points` | Барлық нүктелер, көріністер және фото саны |
| `GET` | `/api/points/{slug}` | Бір нүкте |
| `GET` | `/api/points/{slug}/photos` | Жарияланған фотолар; `year`, `from`, `to`, `cursor` |
| `POST` | `/api/points/{slug}/photos` | Анонимді жүктеу; `client_uuid` қайталауды қауіпсіз етеді |
| `GET` | `/api/export/photos.csv` | Метадеректер CSV түрінде |
| `GET` | `/api/export/photos.geojson` | GeoJSON |
| `GET` | `/api/export/photos.json` | Лицензиясы бар JSON жинағы |
| `GET` | `/api/export/photos.zip` | Суреттер + метадеректер + лицензия |
| `GET` | `/api/health` | Қызмет, дерекқор және сақтау күйі |
| `GET` | `/docs` | Swagger UI |

Толық сипаттама: [`API.md`](API.md) және іске қосылған сервердегі `/docs`.

Жүктеу мысалы:

```bash
curl -X POST http://localhost:8080/api/points/tuyuksu-glacier/photos \
  -F "file=@photo.jpg" \
  -F "viewpoint_id=tuyuksu-glacier-v1" \
  -F "taken_at=2026-07-01T09:00:00Z" \
  -F "client_uuid=$(uuidgen)" \
  -F 'tags={"weather":"clear","snow_cover":"partial"}'
```

## Тесттер

```bash
# Backend
cd backend
./venv/bin/ruff check app tests
./venv/bin/pytest -q                 # 28 тест

# Frontend
cd frontend
npm run lint
npx tsc -b
npm test                             # 14 Vitest тесті
npm run build
npm run e2e                          # Playwright, 3 профиль
```

Backend тесттері EXIF жоюды, беттерді бұлдыратуды, жүктеудің идемпотенттігін,
экспортты және жиілік шектеуін тексереді. Кезек тесті қайта әрекеттерді және
UUID-ді қайта пайдалануды тексереді. Playwright жасанды API қолданады, сондықтан
backend қажет емес.

## Конфигурация

[`.env.example`](../.env.example) файлын `.env` көшіріңіз. Негізгі параметрлер:

| Айнымалы | Әдепкі | Мақсаты |
| --- | --- | --- |
| `DATABASE_URL` | `backend/data/` ішіндегі SQLite | Compose-та `postgresql+psycopg://…` |
| `MEDIA_ROOT` | `./data/media` | Түпнұсқалар мен кіші суреттер |
| `ADMIN_TOKEN` | әзірлеу мәні | **Жарияламас бұрын өзгертіңіз** |
| `IP_HASH_SALT` | әзірлеу мәні | **Жарияламас бұрын өзгертіңіз** |
| `SEED_DEMO` | `true` | Синтетикалық демо-фотолар |
| `UPLOAD_LIMIT_PER_HOUR` | `40` | IP/құрылғы хешіне шаққандағы шек |
| `PUBLIC_BASE_URL` | бос | Экспорттағы абсолютті сілтемелер |

## Құпиялылық және этика

- Тіркелгілер, профильдер, рейтингтер, көшбасшылар тақтасы, сериялар немесе
  белгілер жоқ.
- GPS пен EXIF жүктелмейді және жарияланбайды: оларды клиент те, сервер де жояды.
- Беттер мүмкіндігінше құрылғыда, міндетті түрде серверде бұлдыратылады.
- Үшінші тарап аналитикасы, трекерлер және жарнамалық cookie файлдары жоқ.
- Фотолар **CC BY 4.0** лицензиясымен жарияланады; автор жариялау құқығын
  растайды.
- Әрбір түсіру жолында қауіпсіздік ережелері көрсетіледі. Фото үшін
  белгіленген соқпақтан шықпаңыз, мұздыққа, моренаға, суға немесе тік қарға
  жақындамаңыз.

Толығырақ: [`ETHICS.md`](ETHICS.md) және қосымшадағы «Этика және құпиялылық»
беті.
